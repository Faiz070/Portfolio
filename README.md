# Engineer Portfolio

React + Vite + Tailwind CSS + Framer Motion + Lucide.

## Install
    npm install
## Run (dev)
    npm run dev
## Build for production
    npm run build && npm run preview

## Customize
All content lives in `src/data/portfolio.js`. Replace every `PLACEHOLDER`.
Put `resume.pdf` in `public/`. Set `githubUser` for live GitHub repos.
Update meta/Open Graph tags in `index.html`.
Put profile.jpg (optional) and resume.pdf in public/.
